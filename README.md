# 👋 Hi, I'm Maicon Lucinda

### Security Cloud Engineer — networking roots, security focus

Software Engineering degree, networking roots, and a career that keeps
pulling me back to security.

I started with routing and switching — OSPF, BGP, Spanning Tree — and
learning how traffic actually moves also taught me where it can be
intercepted, spoofed, or left wide open. That is what pushed me into
security. Today I work on AWS: designing VPCs and IAM boundaries,
writing it as code in Terraform, and treating least privilege as a
design decision instead of a cleanup task.

The software engineering side is what ties it together. I read
infrastructure like code, review it like code, and write Python for
the automation and the checks I would rather run than assume.


**What I'm doing right now**
- Building AWS environments with Terraform — VPC, IAM, EKS, security groups
- Writing Python for automation and tooling
- Grinding data structures and algorithms to sharpen problem solving

**How I like to work**
- Infrastructure as code, reviewed like any other change
- Least privilege from the start, not bolted on later
- Read the docs, then verify in the console — assumptions are expensive
